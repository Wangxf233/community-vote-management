# 业主实名认证功能说明

## 功能概述

业主实名认证功能确保只有经过实名认证的业主才能参与投票，提高投票的真实性和准确性。

## 功能流程

### 1. 小程序端 - 业主提交认证

#### 触发时机

- 业主点击投票列表中的任何投票项时
- 系统自动检查该用户的实名认证状态

#### 认证状态判断

- **未认证 (unverified)**: 提示用户需要完成实名认证，引导至认证页面
- **审核中 (pending)**: 显示"正在审核"提示，暂时无法参与投票
- **已通过 (verified)**: 允许进入投票详情页
- **已拒绝 (rejected)**: 显示拒绝原因，可重新提交认证

#### 认证页面 (`/pages/verification/index`)

用户需要上传以下材料：

**必选材料：**

- 身份证人像面
- 身份证国徽面

**三选一材料：**

- 房产证 或
- 购房合同 或
- 缴费证明

**操作步骤：**

1. 点击上传区域
2. 选择相册或拍照
3. 图片自动上传到云存储
4. 选择房产证明类型（单选）
5. 上传对应的证明材料
6. 点击"提交认证"按钮
7. 等待审核结果

### 2. 云函数处理

#### `verifyRealName` - 验证认证状态

- 查询用户的绑定信息
- 查询户主的实名认证状态
- 返回认证状态和拒绝原因（如有）

#### `submitCertification` - 提交认证资料

- 接收身份证和房产证明图片
- 更新 `owner_registry` 表的认证状态为 `pending`
- 保存认证资料链接
- 返回提交结果

### 3. 管理后台 - 审核认证

#### 访问路径

管理后台 → 户主名单 → 实名认证状态为"进行中"的记录 → 点击"审核认证"按钮

#### 审核界面

显示以下信息：

- 户主基本信息（姓名、房号等）
- 提交时间
- 身份证正反面图片（可点击放大查看）
- 房产证明图片（可点击放大查看）

#### 审核操作

1. **通过审核**

   - 选择"通过"单选框
   - 点击"提交审核"
   - 户主的实名认证状态更新为"已实名"
   - 业主可以正常参与投票

2. **拒绝审核**
   - 选择"拒绝"单选框
   - 输入拒绝原因（必填）
   - 点击"提交审核"
   - 户主的实名认证状态更新为"未通过"
   - 业主需要重新提交认证资料

## 数据库字段说明

### owner_registry 表新增字段

| 字段名               | 类型   | 说明                                           |
| -------------------- | ------ | ---------------------------------------------- |
| realNameStatus       | String | 认证状态：unverified/pending/verified/rejected |
| realNameIdCardFront  | String | 身份证正面图片 URL                             |
| realNameIdCardBack   | String | 身份证反面图片 URL                             |
| realNameCertType     | String | 证明类型：property/contract/payment            |
| realNameCertImage    | String | 房产证明图片 URL                               |
| realNameSubmitTime   | String | 提交时间（ISO 格式）                           |
| realNameRejectReason | String | 拒绝原因（仅 rejected 状态有值）               |

## API 接口

### 后端路由

```
POST /api/owner-registry/:id/realname-review
```

**请求参数：**

```json
{
  "status": "approved" | "rejected",
  "rejectReason": "拒绝原因（status为rejected时必填）"
}
```

**响应：**

```json
{
  "success": true
}
```

## 注意事项

1. **图片存储**

   - 图片存储在云存储的 `verification/` 目录下
   - 按类型分文件夹：id-card-front、id-card-back、property-cert、contract、payment

2. **家属账号**

   - 家属账号不支持投票功能
   - 家属账号无需实名认证

3. **审核时效**

   - 建议在 24 小时内完成审核
   - 可通过消息推送通知业主审核结果

4. **重新认证**
   - 审核拒绝后，业主可立即重新提交
   - 新提交会覆盖原有资料
