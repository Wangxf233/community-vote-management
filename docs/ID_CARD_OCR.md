# 身份证OCR识别功能说明

## 功能概述

在实名认证页面上传身份证时，系统会自动进行OCR识别，检测图片质量并提取身份证信息。

## 功能特性

### 1. 图片质量检测

- **质量评分**：0-100分，建议≥50分
- **复印件检测**：识别是否为复印件
- **翻拍检测**：识别是否为屏幕翻拍
- **PS检测**：识别是否经过PS处理
- **边框检测**：检测边框是否完整
- **临时身份证检测**：识别是否为临时身份证

### 2. 信息识别

**正面识别信息：**

- 姓名
- 性别
- 民族
- 出生日期
- 地址
- 身份证号码

**反面识别信息：**

- 签发机关
- 有效期限

### 3. 用户体验

- 上传后自动识别
- 显示识别结果供用户确认
- 质量不合格时提示重新拍摄
- 识别失败时可选择继续使用或重新上传

## 部署步骤

### 1. 安装依赖

在云函数目录执行：

```bash
cd cloudfunctions/idCardOCR
npm install
```

### 2. 配置腾讯云密钥

在云函数环境变量中配置：

- `TENCENT_SECRET_ID`：腾讯云SecretId
- `TENCENT_SECRET_KEY`：腾讯云SecretKey

获取方式：

1. 登录腾讯云控制台
2. 进入"访问管理" > "访问密钥" > "API密钥管理"
3. 创建密钥并保存

### 3. 开通OCR服务

1. 登录腾讯云控制台
2. 搜索"文字识别OCR"
3. 开通"身份证识别"服务
4. 查看定价和免费额度

### 4. 上传云函数

```bash
# 在cloudfunctions/idCardOCR目录
npm install
# 右键点击idCardOCR文件夹，选择"上传并部署：云端安装依赖"
```

### 5. 测试功能

在小程序中：

1. 进入实名认证页面
2. 点击上传身份证
3. 选择身份证照片
4. 等待自动识别
5. 查看识别结果

## 计费说明

腾讯云身份证OCR识别：

- 免费额度：每月1000次
- 超出后：0.15元/次（人像面）、0.10元/次（国徽面）

建议：

- 在云函数中缓存识别结果
- 避免重复识别同一张图片

## 错误处理

### 常见错误

1. **图片质量过低**
   - 提示用户重新拍摄
   - 建议：光线充足、对焦清晰、避免反光

2. **识别失败**
   - 允许用户继续使用原图
   - 人工审核时会再次检查

3. **网络错误**
   - 自动重试机制
   - 超时提示用户重新上传

## 隐私和安全

1. **数据加密**：图片传输和存储均加密
2. **权限控制**：仅授权用户可访问
3. **数据保留**：识别数据仅用于认证，不做他用
4. **定期清理**：审核通过后可选择删除原图

## 优化建议

1. **图片压缩**：上传前压缩图片，节省流量
2. **缓存机制**：识别结果缓存，避免重复请求
3. **离线识别**：集成端侧OCR，减少云端调用
4. **批量处理**：支持同时上传正反面一起识别
