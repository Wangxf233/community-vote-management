# MQTT-HTTP接口文档 2.6

\*\*url: http://web.fondcard.net/open/mqtt/api.php?method=xxxx

\*\* content-type: application/x-www-form-urlencoded

## 添加设备 ?method=data.device.add

+-----------------------------------------------------------------------------------------------------------+
| **POST参数**                                                                                              |
+====================+====================+====================+============================================+
| serial             | 字符串             | 必填               | 设备系列号                                 |
+--------------------+--------------------+--------------------+--------------------------------------------+
| password           | 字符串             | 必填               | 设备密码                                   |
+--------------------+--------------------+--------------------+--------------------------------------------+
| deviceNo           | 数字               | 必填               | 出厂编号                                   |
+--------------------+--------------------+--------------------+--------------------------------------------+
| ~~deviceId~~       | ~~数字~~           | ~~必填~~           | ~~设备表ID~~ 2.4版本不再需要               |
+--------------------+--------------------+--------------------+--------------------------------------------+
| deviceType         | 数字               | 必填               | 设备类型 0-读头 1-门禁                     |
+--------------------+--------------------+--------------------+--------------------------------------------+
| mac                | 字符串             | 必填               | MAC                                        |
+--------------------+--------------------+--------------------+--------------------------------------------+
| btkey              | 字符串             |                    |                                            |
+--------------------+--------------------+--------------------+--------------------------------------------+
| btkeyType          | 数字               |                    |                                            |
+--------------------+--------------------+--------------------+--------------------------------------------+
| algorithm          | 数字               | 必填               | 人脸算法 0-3288 1-520 2-商汤 4-阿里 3-其他 |
+--------------------+--------------------+--------------------+--------------------------------------------+
| scanOpen           | 数字               |                    | 用户扫二维码不判断权限直接开门 0-否 1-是   |
+--------------------+--------------------+--------------------+--------------------------------------------+
| platform           | 字符串             | 必填               | 平台/应用名 2.4版本必填                    |
+--------------------+--------------------+--------------------+--------------------------------------------+
| **服务器回复**                                                                                            |
+-----------------------------------------------------------------------------------------------------------+
| {                                                                                                         |
|                                                                                                           |
| > code:0, /\*0错误代码表见附表\*/                                                                         |
| >                                                                                                         |
| > message:\"\"                                                                                            |
| >                                                                                                         |
| > data:{                                                                                                  |
| >                                                                                                         |
| > id:111 /\*2.4版本返回该值，对应老版本的deviceId\*/                                                      |
| >                                                                                                         |
| > }                                                                                                       |
|                                                                                                           |
| }                                                                                                         |
+-----------------------------------------------------------------------------------------------------------+

### 二维码规则：

**访客二维码规则:\**
F2/设备id/用户id/访问类型/有效期/生成时间 (设备id，多个用半角逗号隔开)\
访问类型：0-不限次 3-一次 5-两次\
\
**用户二维码规则：\**
M+base64(long2bytes(用户id) +long2bytes(索引) + long2bytes(生成时间))

\*\*实际没有加号

**授权二维码规则:\**
F1/设备id/用户id/访问类型/有效期/生成时间 (设备id，多个用半角逗号隔开)\
访问类型：0-不限次 3-一次 5-两次
