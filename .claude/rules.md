# 项目通用强制规则

> 这些规则在所有场景下自动生效，无需加载任何 Skill。

## 代码红线

1. **禁止在代码中硬编码密钥、token、密码** — 一律通过环境变量或配置注入
2. **禁止在日志/错误响应中打印手机号、身份证号、完整地址** — 调试时必须脱敏：`phone.slice(0,3) + '****' + phone.slice(7)`
3. **禁止提交包含 `.env` 或真实密钥的代码** — 密钥只能存在于本地 `.env` 文件（已在 .gitignore）
4. **禁止在 catch 块中只 `console.error` 不处理错误** — 必须返回/提示用户友好的错误信息
5. **禁止在用户可见的错误信息中暴露内部实现细节** — 包括 `err.message`、`err.stack`、`JSON.stringify(err)`

## 项目约定

6. **新增 API 必须先更新 `docs/api.md` 再实现**
7. **数据结构变更必须同步更新 `shared/types.ts`**（Stage 2 创建后生效）
8. **修改已有云函数时，若返回格式非 `{success, error}` 标准，需同步迁移**
9. **修改已有管理后台页面时，若该页面展示手机号/身份证明文，需同步添加脱敏**
10. **修改已有 Express 路由时，若该路由缺少输入验证，需同步添加 validate schema**（Stage 2 创建后生效）

## 隐私与安全

11. **前端展示手机号**：前 3 后 4，中间 4 位掩码 → `138****1234`
12. **前端展示身份证号**：前 4 后 4，中间 10 位掩码 → `3301**********1234`
13. **多租户隔离**：所有数据库查询必须过滤 `communityId`，不得跨社区访问数据
14. **敏感操作审计**：查看完整隐私数据、数据导出、权限变更必须记录审计日志

## Claude Code 使用约定

15. **开发功能时自动使用专用 Agent** — 无需手动指定，描述需求即可
16. **功能开发完成后必须写测试** — test-writer agent 自动触发
17. **提交前运行对应端的 lint 命令确认无报错**
18. **不要修改 `.claude/` 目录下由本项目生成的配置文件** — 如需调整规范，编辑对应的 Skill 文件

## 文档同步规则

19. **每次代码修改后必须同步更新 `CHANGELOG.md`**
    - 新增功能 → `### Added`
    - 修复缺陷 → `### Fixed`
    - 重构代码 → `### Changed`
    - 删除功能 → `### Removed`
    - 安全修复 → `### Security`
20. **新增/修改 REST API 后必须同步更新 `docs/api.md`**
21. **新增/修改云函数参数后必须同步更新云函数目录下的 README.md（如 `cloudfunctions/createVote/README.md`）**
